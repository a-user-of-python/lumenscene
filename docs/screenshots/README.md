# Screenshots

Drop screenshot images into this folder using exactly these filenames,
and they will appear in the Screenshots section of the top-level
[README](../../README.md) (the image lines there are waiting in an
HTML comment — remove the comment markers once the files exist):

| File | What to capture |
| --- | --- |
| `editor.png` | The editor: object tree, viewport, properties |
| `play.png` | Play mode: first-person walk-around |
| `weather-rain.png` | A scene with rain running |
| `nodes.png` | The node editor with a working graph |
| `final-render.png` | A finished Final Render (Render Image…) |

PNG or JPG both work — if you use JPG, update the extension in the
README's Screenshots section to match.
